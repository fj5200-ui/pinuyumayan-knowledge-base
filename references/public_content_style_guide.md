# 卑南族公開內容寫作規範

## 1. 語氣

- 使用「公開資料指出」「公開介紹提到」「可理解為」等保守表述。
- 避免把起源傳說、祭儀脈絡、部落差異寫成單一、排他的定論。
- 不用獵奇、神秘化、娛樂化語氣描述祖靈、巫師、猴祭、大獵祭與會所訓練。

## 2. 結構

建議前台內容卡欄位：

```json
{
  "title_zh": "",
  "summary_zh": "",
  "source_ids": [],
  "sensitivity": "low|medium|high",
  "review_status": "verified_public|needs_community_review",
  "public_rendering_rule": "public_article_allowed|summary_only"
}
```

## 3. 禁止寫法

- 「教你如何做猴祭/大獵祭/巫師儀式」
- 「卑南族標準祭儀流程如下」
- 「所有卑南族人都……」
- 「Puyuma = 卑南族」
- 「卑南族八社」作為正式平台分類
- 未查證人物生平、作品或部落公告日期

## 4. 建議寫法

- 「依原住民族委員會公開介紹，……」
- 「此主題涉及部落與祭儀脈絡，平台僅提供公開摘要。」
- 「實際日期與開放範圍，請以部落公告為準。」
- 「不同部落可能有不同做法，需經部落/族人複核。」
