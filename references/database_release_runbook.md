# Database Ops v4 Release Runbook

## 1. 驗收

```bash
python3 scripts/validate_package.py
python3 scripts/validate_database_layer.py
python3 scripts/validate_operational_database_layer.py
python3 scripts/validate_web_vocabulary.py
python3 scripts/validate_full_corpus_pipeline.py
python3 -m py_compile scripts/*.py
```

## 2. 匯入順序

1. 建立核心資料表：`pinuyumayan_mysql_tidb_schema.sql`
2. 建立索引與 view：`pinuyumayan_sql_views_and_indexes.sql`
3. 匯入來源與 facts seed。
4. 匯入 `puyuma_corpus_entries` preview subset。
5. 建立 review queue。
6. 重建搜尋索引。
7. 啟用後台 dashboard widgets。

## 3. 上線前人工檢查

- 高敏感內容是否仍需審核。
- 音檔鏡像是否取得授權。
- TTS 是否保持關閉。
- 搜尋索引是否排除未審核 high sensitivity 內容。
- 前台是否清楚標示來源與授權。

## 4. 回滾

若驗收失敗：

1. 停用新建 views。
2. 移除 autogenerated review queue pending tasks。
3. 回復上一版 seed bundle。
4. 重建上一版搜尋索引。
