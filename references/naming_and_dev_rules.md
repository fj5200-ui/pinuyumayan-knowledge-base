# 卑南族文化綜合平台開發指南 (Development Guidelines)

## 1. 族群正名與稱呼規範

在所有 AI 摘要、文本生成、介面顯示、資料庫 seed 與 API 回傳中，必須嚴格遵守以下稱呼規範：

* **絕對禁止**使用「普悠瑪族」這個錯誤稱呼。
* **族群整體**必須使用「卑南族」或「Pinuyumayan」。
* **Puyuma** 僅指南王部落；英文語境中若指語言，請寫成 **Puyuma language**。
* 提及部落分類時，**必須**使用「卑南族十社」（Pinuyumayan Ten Communities），不得將「八社」作為正式分類。
* 十社名稱、羅馬拼音主用版、異名與工程 key 以 `references/tribe_name_authority.md` 為最高優先準則。

## 2. 族語學習頁面 (`/language`) 規範

為了提升使用者的學習動機與參與度，族語學習頁面必須實作以下功能與佈局：

### 2.1 快速存取區 (Quick Access)

在 Hero banner 下方，必須加入「快速存取區」，包含以下卡片：

1. **今日挑戰 (Today's Challenge)**
2. **繼續學習 (Continue Learning)**
3. **詞彙排行榜 (Vocabulary Leaderboard)**
4. **每日測驗 (Daily Quiz)**：連結至 `/language/quiz`，若已完成則顯示綠色打勾圖示。

### 2.2 詞彙展示與佈局

* **網格佈局**：詞彙展示必須採用網格佈局（例如 4 欄 4 列）。
* **動態卡片**：SVG 大圖卡片必須是動態且可修改的。若無法一次顯示所有詞彙，必須提供「載入更多 (load more)」功能。
* **排序規則**：卡片順序必須依據詞彙量，由左至右、由上至下排列。

### 2.3 語音與互動 (TTS)

* **語音播放**：在詞彙詳細頁面或卡片上，必須加入 TTS 播放按鈕。
* **方言支援**：TTS 系統必須支援南王、知本、建和、西群四種方言的切換。

### 2.4 學習進度追蹤 (Progress Tracking)

* **個人紀錄**：系統必須包含個人學習紀錄（例如：已學詞彙、連續學習天數、測驗分數趨勢）。
* **快速連結**：在族語學習頁面 (`/language`) 的頂部或側邊欄，必須加入「我的學習進度 (My Learning Progress)」快速連結。
* **測驗紀錄**：在 LanguageQuiz 完成頁面，必須呼叫 `recordQuizCompletion` 函數，以確保學習進度資料被正確累積。
* **遊戲化機制**：引入里程碑徽章系統。

## 3. 文化內容頁面 (`/culture`) 規範

### 3.1 文化人物 (Cultural Figures)

* **詳細頁面**：點擊文化人物卡片後，必須導向專屬的詳細頁面 (`/culture/figures/:id`)。
* **資料匯入**：文化人物的 `content` 欄位應透過後台編輯或批次匯入功能來填入。

### 3.2 影音媒體 (Audio/Video Media)

* **擴充分類**：影音媒體的分類必須擴充，包含「紀錄片 (Documentaries)」、「祭儀樂舞 (Ritual Songs and Dances)」等類型。
* **後台管理**：在後台的文化內容管理中，必須增加專屬的「影音媒體」分頁，用於新增、編輯與刪除媒體資料。
* **語音資源整合**：在開發語言學習或 TTS 相關功能時，應優先使用 Google Drive (Folder ID: `1mdzXxD5XQAVLIAdrD5xy3iRI7B3XnlUo`) 中已整理好的 MP3 音訊檔案（包含 ePark 與 ILRDF 字典音訊）。

## 4. 部落介紹頁面規範

* **區塊命名**：部落介紹區塊必須命名為「卑南族十社 (Pinuyumayan Ten Communities)」。
* **卡片展示**：所有部落卡片必須以垂直捲動方式列出，並連結至各自的詳細內容頁面。
* **資料來源**：部落名稱與羅馬拼音必須引用 `references/tribe_name_authority.md` 的主用表。

## 卑南族文化綜合平台 Development Standards

For detailed UI/UX and feature specs, read: `references/naming_and_dev_rules.md`

Key rules (summary):
- `/language` page: add Quick Access cards (今日挑戰, 繼續學習, 詞彙排行榜, 每日測驗), grid vocab layout (4-col), TTS play button per word, learning progress tracking with `recordQuizCompletion`.
- `/culture` page: cultural figures link to `/culture/figures/:id`; expand media categories (紀錄片, 祭儀樂舞).
- Tribe intro: rename「認識八社」→「卑南族十社」, vertical scroll card list.

### Language Learning App Specifications
- **Gamification**: Implement milestone badges for consecutive learning days and vocabulary completion.
- **Quiz System**: Support CSV/PDF export for quiz results, customizable notification times, and batch deletion in the admin backend.
- **Vector Search**: Implement pgvector Hybrid Search for vocabulary and articles, with a daily automatic incremental update schedule.
- **Personalization**: Display recommended articles and vocabulary on the homepage based on user browsing history.

### API Development Guidelines
- **TTS API**: Must support `dialect` parameter (Nanwang, Zhiben, Jianhe, Xiqun). Include a scheduled task (e.g., 3:00 AM) to pre-heat uncached vocabulary.
- **Vocabulary API**: Serve structured JSON data from `data/puyuma_vocab_index.json` when generated by `scripts/parse_puyuma_corpus.py` (17,584 sentences, 7,073 dictionary entries).
- **Subscription API**: Integrate ECPay for premium content (e.g., full language courses, audio downloads). Implement a webhook for payment verification and an automated daily cron job to downgrade expired subscriptions.

### 傳統建築詳細規格
- **家屋 (ruma)**：卑南族傳統家屋為長方形，以竹、木、茅草為主要建材。家屋內部通常有三個石灶，分別用於煮食、取暖與祭祀。
- **祖靈屋 (karuma'an)**：各家族的祭祀中心，由家族長女管理。建築特色為小巧、隱密，內部供奉祖靈，非家族成員或特定祭祀期間有嚴格禁忌禁止進入。
- **會所 (trakuban / palakuwan)**：
  - **少年會所 (trakuban)**：高干欄式建築，圓形或橢圓形，外徑約 11 公尺，供 12-18 歲少年居住與訓練。
  - **青年會所 (palakuwan)**：長方形建築，供成年未婚男性居住，是部落防禦與決策中心。

### 卑南族與原住民族政策互動
- **原住民族基本法 (2005)**：保障卑南族土地、語言與文化權利，推動部落自治。
- **知本光電案**：涉及卡大地布部落傳統領域土地權益，引發部落諮商同意權的法律與社會爭議，最終部落勝訴，成為原住民族土地權利重要判例。
- **族語教育政策**：推動族語認證、花環實驗小學成立，以及 ILRDF 數位語料庫建置。

### 傳統漁獵工具
- **弓箭 (pana)**：用於狩獵中小型動物，弓身多用竹或木製，箭頭早期為削尖竹木，後改用鐵器。
- **長矛 (vulu)**：用於近戰或狩獵大型動物（如山豬），長度約 1.5-2 公尺。
- **番刀 (trakal)**：卑南族男性必備工具，用於開路、狩獵與防身，刀鞘常有精美雕刻。
- **魚筌 (rakar)**：竹編漏斗狀陷阱，放置於河川中捕魚，魚能進不能出。

### 傳統編織技術
- **水平背帶織布機 (tatenunan)**：織者坐於地面，一端繫於腰部，另一端固定，透過身體前後移動調節經線張力。最大織布寬幅約 30 公分。
- **月桃葉編織**：用於製作草蓆、置物簍等日常用品。
- **圖案象徵**：常見菱形紋、人形紋，十字繡為南王部落特色。

### 現代藝術與文化創作
- **哈古 (陳文生)**：建和部落木雕家，作品圍繞祖靈傳說與祭儀，2025 年獲認定為「卑南族 tu'tu' 木雕」重要傳統工藝保存者。
- **巴代**：卑南族小說家，作品如《笛鸛》、《斯卡羅人》深入描寫原住民族歷史與文化。
- **音樂創作**：紀曉君、陳建年、桑布伊等歌手將傳統古調與現代音樂結合，多次獲金曲獎肯定。

### 傳統社會階層與性別角色
- **母系社會**：財產繼承與姓氏傳遞由女性（長女）負責，婚姻採男方入贅（從妻居）。
- **男性會所制度**：男性負責部落公共事務、政治、軍事與宗教祭祀，形成「男主外、女主內」的性別分工。

### 外來文化融合
- **天主教 (白冷會)**：在南王部落推動本土化，陸森寶創作融合卑南語的聖歌。
- **長老教會**：在知本等部落發展，推動母語聖經翻譯。
- **日本文化影響**：影響音樂旋律、教育制度與部分服飾元素。

### 知識圖譜與 AI 問答

- **結構化知識**：將 SKILL.md 中的 100+ 個主題轉化為知識圖譜（Knowledge Graph），建立實體（如祭儀、神話人物）間的關聯。

- **FormosanBank 深度整合**：透過 API 串接 FormosanBank 語料庫，在學習 App 中提供即時的例句檢索與發音比對功能。
