## 候選來源規則

候選來源必須通過：

- URL 與出版者人工確認
- 授權檢查
- 卑南文化遺址禁止關聯檢查

- 來源摘錄不得超過授權限制
- 高敏感文化內容只能做 public summary 或 restricted summary
