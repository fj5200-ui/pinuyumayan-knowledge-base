# v33 來源候選審核

候選來源不得直接公開。審核順序：

1. fetchability：能否取得原始頁面或 API。
2. publisher authenticity：確認來源是否為官方、地方政府、博物館、學術機構、部落公開頁面。
3. license：授權是否允許摘要、引用、索引或音檔播放。
4. duplicate：與既有 claim/card/source packet 去重。
5. forbidden relation：不得把卑南文化遺址當卑南族文化來源。
6. sensitivity：祭儀、信仰、人物、部落內部知識需加敏感標籤。
7. human review：人工確認後才可 promotion。
