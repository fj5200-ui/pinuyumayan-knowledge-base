# v14 Content Quality Upgrade

Content enrichment stays source-bound. New content tasks are created from existing verified facts, community records, and ritual public summaries.

Public release blockers:

- Missing source ID.
- Unapproved status.
- Restricted or admin-only fields.
- Private ritual procedure or taboo detail.
- Unverified exact dates.
- Unreviewed license for audio mirroring.

Run `python3 scripts/validate_upgrade_optimization_v14.py` before packaging or deployment.
