# 卑南族 (Pinuyumayan) 文化知識深度報告

## 1. 族群概述與社會制度
卑南族以其**嚴密的社會組織**與**會所制度**聞名於原住民族群。

### 會所制度 (Takoban & Parakoan)
*   **少年會所 (Takoban)**：男子約 11-12 歲進入，接受體能、狩獵、禮儀等基礎訓練。
*   **青年會所 (Parakoan)**：男子成年後進入，為部落的軍事與公共事務核心。
*   **年齡階級**：男子一生依年齡分為多個階級，每個階級有其特定的社會責任與權利，這種制度強化了部落的凝聚力。

### 政治與祭祀領袖
*   **Ayawan**：傳統政治領袖，負責領導獵首、征戰與部落重大事務。
*   **Rahan**：祭司，掌管祭祀禮儀，是精神世界的領導者。

## 2. 重要祭典與儀式
卑南族的祭典多與男子的成長階段及自然時序掛鉤。

### 大獵祭 (Mangayaw)
*   **時間**：每年 12 月底。
*   **意義**：卑南族最重要的祭典，結合了男子成年禮、除喪儀式與對祖靈的敬重。
*   **核心**：男子集體上山狩獵，返鄉時由女性長輩戴上花環，象徵勇士的回歸與身份轉換。

### 猴祭 (Mangayangayaw)
*   **對象**：少年會所的成員。
*   **目的**：透過刺草猴的儀式，訓練少年的勇氣與團隊精神，是進入成年階級前的「縮小版大獵祭」。

### 海祭 (Mulalriyaban)
*   **意義**：祭祀海神與祖靈，感謝自然資源的饋贈，部分部落仍保有此傳統。

## 3. 物質文化與傳統工藝
卑南族的美學體現在其服飾與日常器具中。

### 花環文化 (Pukid)
*   **象徵**：卑南族最具代表性的標誌。象徵榮耀、祝福與美的追求。
*   **用途**：男女老少皆可配戴，不同場合有不同的編織法，體現了與自然和諧共處的哲學。

### 傳統織布 (Tenun)
*   **技法**：以**夾織**技法聞名，能表現複雜的圖紋，與其他族群的平織有顯著差異。
*   **圖紋**：織紋蘊含族群記憶，已被登錄為重要文化資產。

### 建築工藝
*   **會所建築**：傳統上為圓形或長方形干欄式建築，以竹、藤、木材搭建。
*   **祖靈屋**：女巫師（Maritaban）的祭祀場所，屋內東北角為最神聖的方位。

## 4. 延伸知識：卑南族十社 (Puyuma Ten Communities)
傳統上卑南族有「八社」之稱，但實際包含更多部落，現多稱為「卑南族十社」，包括：
*   南王 (Nanwang/Puyuma)
*   知本 (Zhiben/Katratripulr)
*   建和 (Jianhe/Kasavakan)
*   初鹿 (Chulu/Ulivelivek)
*   賓朗 (Pinlang/Pinaski)
*   利嘉 (Lijia/Likavung)
*   泰安 (Taian/Tamalakaw)
*   大巴六九 (Tamalakaw)
*   寶桑 (Pausang) 等。

## 5. 知識與語料的關聯
在之前的語料報告中，許多詞彙如 `parakoan` (會所)、`mangayaw` (大獵祭)、`pukid` (花環) 皆有對應的音檔與 IPA，建議使用者可結合此文化報告與語料 JSON 進行深度學習。
